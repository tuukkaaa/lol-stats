# LoL Stats Tracker

Nextjs app taht integrates with the Riot Games API


##  Features

### Summoner Search

### Match History

### Ranked Statistics

### Live Game Tracking

### Tech 

- **Framework**: Next.js 14
- **Language**: JavaScript
- **Styling**: TailwindCSS + shadcn
- **Data Fetching**: SWR caching
- **API Integration**: Riot Games API
- **Icons**: Lucide React
- **Deployment**: Vercel
